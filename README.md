# GamePacketEditorDemo

Учебное приложение на C++ и Qt Widgets для редактирования полей сетевых
пакетов игровых персонажей. Используется собственный учебный формат из двух
56-битных пакетов, а не протокол конкретной игры.

Версия 0.1.0.

Пакеты:

- `CharacterState` — тип объекта, режим, состояние персонажа,
  идентификатор персонажа и резервные биты.
- `CharacterAppearance` — тип объекта, класс персонажа и восемь кодов
  элементов экипировки: головной убор, нагрудник, перчатки, поножи,
  обувь, оружие, щит и аксессуар.

Поля редактируются в дереве слева. После изменения поля модель пересчитывает
числовое значение пакета, таблица подсвечивает изменение, а таймер раз в секунду
добавляет актуальное значение изменённых пакетов в журнал. Значения пакетов
показаны в десятичной системе. Столбцы `First Bit` и `Last Bit` задают включительные
границы поля с нумерацией от 1. Восемь кодов экипировки занимают по 6 бит каждый.

Приложение использует MVC с тремя ролями:

- Модель — `PacketModel` (`QAbstractItemModel`) и узлы `PacketItem`.
  Модель хранит дерево и выполняет кодирование пакетов.
- Представление — виджеты дерева, таблицы и журнала в `mainwindow.ui`.
- Контроллер — обработчики `MainWindow`, которые связывают
  уведомления модели с таблицей и журналом.

Модель и представление взаимодействуют через механизм Qt Model/View,
а роль контроллера выполняет класс окна `MainWindow`.
Приложение демонстрирует кодирование и отображение пакетов без сетевой отправки.

Начальная структура и значения полей находятся в `packets.txt`.
Файл встроен в ресурсы приложения через `GamePacketEditorDemo.qrc`.

Для сборки нужны Qt 5.15 с модулем Widgets, qmake, make и компилятор C++11.
В Qt Creator откройте `GamePacketEditorDemo.pro` и соберите проект.
Для сборки из командной строки вне каталога исходников:

```sh
mkdir build
cd build
qmake ../GamePacketEditorDemo.pro
make
```
